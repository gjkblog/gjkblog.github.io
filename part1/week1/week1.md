#### **机器学习**

我们知道，AI的训练基于数据。我们不难得出，AI正是通过对数据进行某项加工，得出一定的规律，从而能够应对新输入的数据，给出一定的输出。学过生物学的也许知道，人脑的神经元就是不断地建立反射（创建规律），才有了我们的复杂行动

那么，机器学习，一句话，就是对数据找规律。

我们不妨考虑一个最简单的例子：我给你10个点：$(x1,y1),(x2,y2),...(x10,y10)$。那么，请你根据这些点，找出一个可能预测的规律，并预测一下，当$x=a时，y是多少$

那么你至少应该知道这是统计学的范畴，我们找一个函数模型，代入这些点，来拟合出一个函数，这个函数就是我们找的规律
然后，我们就可以用这个函数，来预测当$x=a%时，$y$是多少

你也知道有好几种函数，$y=e^x，y=kx......$，这里我们以线性回归为例

###### 函数模型

$$
y=wx+b
$$

###### 损失函数

设有n个点$(x_i,y_i)$
我们于是用方差来表示损失函数：

$$
J(w,b)=\frac{1}{n}\sum_{i=1}^{m}[wx_i+b-y_i]^2
$$

我们考虑单个点的残差：

$$
r_i=wx_i+b-y_i
$$

###### 具体讲解 初步想法

先来讲讲这个损失函数吧。我们直接用$J$表示，括号那两个参数就是上面函数模型的$w,b$

你看式子应该能看明白，$J(w,b)$表示的是所有点的残差的平方和的平均值。显然，$J(w,b)$越小，说明模型拟合得越好

那么我们的目的很明显了，输入新数据的时候，要求将这个$J(w,b)$往减小的方向走

###### 具体讲解 实现方法

高中我们学过最小二乘法，因此首先我们可以考虑，每次添加新数据的时候，算一次最小二乘法，来更新我们的模型参数$w,b$

然而，**这个方法有几个问题：**

1. 每次添加新数据，都需要重新计算一次最小二乘法，这会很耗时。
2. 如果出现一个错误的数据，我们的模型是不会识别它是否错误的，因此我们的模型参数$w,b$会继续往错误的方向走。
3. 假如你没学过算法，那么你现在去学，需要很长的适应期。我们的数据预测同理，理想状态下它应该需要一个缓慢转变的过程，而不是被左右

那么，大的来了

**梯度下降算法**

我们考虑如何将$J(w,b)$往减小的方向走。首先我们对$w$求偏导

$$
\frac{d}{dw}J(w,b)=\frac{1}{n}\sum_{i=1}^{m}[wx_i+b-y_i]x_i=\frac{1}{n}\sum_{i=1}^{m}r_i x_i
$$

同理对$b$求偏导

$$
\frac{d}{db}J(w,b)=\frac{1}{n}\sum_{i=1}^{m}r_i
$$

显然，要想将$J(w,b)$往减小的方向走，我们需要同时更新$w,b$，根据导数来更新。导数大于0时，我们期望$w,b$往减小的方向走，导数小于0时，我们期望$w,b$往增大的方向走

机器学习给的算法是:定义一个学习率$\alpha$，每次更新$w,b$时，都用$\alpha$来乘以导数，来更新$w,b$

具体公式如下：

$$
w=w-\alpha\frac{1}{n}\sum_{i=1}^{m}r_i x_i
$$

$$
b=b-\alpha\frac{1}{n}\sum_{i=1}^{m}r_i
$$

这是对于所有数据，进行一个整体的更新公式

当然，你加入一个新的点的时候，$J(w,b)$增加的值只取决于$r_i$，这个应该不难看出来

因此，我们也可以只通过这一个点的增长，来更新$w,b$。下面给出公式：

$$
w=w-\alpha r_i x_i
$$

$$
b=b-\alpha r_i
$$

先不分析式子，我们用代码实现一下

```python
def update_w_b(w,b,r_i,x_i,alpha)->tuple:
    w=w-alpha*r_i*x_i
    b=b-alpha*r_i
    return w, b
```

> r_i表示残差$r_i=wx_i+b-y_i$，$x_i$表示输入数据，$y_i$表示目标输出数据，是我们期望得到的答案
> 那么问题来了，$J$的导数为什么作为因子参与更新？原则上$w,b$关于$J$的函数，应该是上面导数的倒数，故我们的初始想法是根据牛顿法来更新$w,b$，说白了，就是根据$J(w,b)$的导数的导数，来更新$w,b$

不过面临2个大问题:

1. 计算机算小数、分数复杂，耗时
2. 存在精度问题

原则上给你一个不变的实数$a$，你可以用另一个你像让它等于多少就多少的实数$k$，用$ak$表示任何实数，因此我们可以用上面的导数乘以$\alpha$，来作为单次步长更新$w,b$

于是我们这一步的核心原理就讲完了，你会发现，梯度下降算法的实现，其实就是用$\alpha$来乘以导数，来更新$w,b$

也因此，你会注意到，接下来的关键就是把学习率$\alpha$设置得合适，否则会导致模型参数$w,b$的更新过快，或者过慢，从而影响模型的训练效果

###### 具体讲解 学习率$\alpha$的设定

> 前排提示：这些符号不是全世界统一的，我只是随便挑个来做形式表达，你用$u$表示学习率什么的都可以

首先，学习率可以是一个常数，就是说每次的$\alpha$就是一个固定的值，不会变化。这个很简单，你多试几个，找到个好的值就可以了，因此这里我们考虑**动态变化**的学习率

学习率干啥用呢？比如，很简单，你也不能快速地让自己成为一个掌握了所有深度学习知识的人，我给你这个博客，你不太是可能看完就理解，你需要时间，模型也是这样，太大的跨度容易引起更大的误差。**学习率作为一个步长的限制，可以防止模型参数$w,b$的更新过快，或者过慢，从而影响模型的训练效果**

学习率的维护有两个大模式，分别是**调度式**和**自适应式**。这俩的区别是，前者就是写在DNA的变化，而后者则需要根据具体数据

举个**调度式**的简单的例子：

$$
\alpha=\alpha_{0} q^{\frac{t}{T}}
$$

这个你应该能看懂，我们固定一个周期T，然后根据当前的迭代次数$t$，让这个系数变化，来调整$\alpha$

显然它与数据无关，你可以在网上搜搜其他的**调度式**的学习率计算，都不考虑数据

**调度式**的好处就是设计简单，实现简单，维护起来简单。坏处就是，数据变化的时候，学习率不好适应，因此我们来看看**自适应式**

**自适应式**

这个麻烦了点，我们需要根据数据的变化，来动态调整$\alpha$，不管是写公式还是维护，都比较难办。自适应式的变化有以下两个维度：

- 逐参数：不同参数的梯度尺度不同，步长应不同
- 逐时刻：同一参数在不同阶段，步长应变化（梯度大时小步，梯度小时大步）

这个就是数学的问题了，原则上会有非常多的函数模型。比如，既然是想让$w$根据$J$关于$w$的导数来更新，那么以微分思想，导数近似于$\frac{J(w,b)}{w}$，那么显然，$\alpha$应该把它反过来转为$w$关于$L$的关系，来调整$w$，$b$同理

我们就能得出一个可能的关系：

$$
\alpha=frac{k}{L}*q^{t/T}
$$

我们考虑到，想让模型主要关心前面的数据，后面就要保持别动了，因此我们定义一个$q$，根据输入数据的轮数,来控制$\alpha$的变化，T是一个可能的变化周期

那么我们对于**机器学习**就讨论在这里结束了。如果你忽略掉那些式子，原理还是很好懂的：

```
确定函数模型，如y=wx+b
        ⬇️
根据输入输出动态调整w,b(用学习率来确定变化量，学习率也是动态变化的)
        ⬇️
足够的训练后，模型的w,b会收敛到一个最优解，从而得到一个最优的模型
```

上面这是机器学习的一个大体流程，目前广泛的机器学习就是通过学习率这一套来调整参数。可能部分机器学习也有其他方法，但整体流程思想是一致的

此外，对于其他函数模型，比如$y=e^x$什么的，也是一个道理

我们也能够让一个程序内置多个模型，动态切换，来适应不同的任务，同时给定一系列的数据，也让它能够自动选择最优的模型。具体的实现，你可以考虑每个模型的损失函数，来判断哪个模型更优，就是说一批数据让每个函数模型都跑一遍，然后根据损失函数来判断哪个模型更优。至于更快的方法，有兴趣可以去研究，我目前的研究方向不在这里。

#### **表示学习**

讲了那么长的机器学习，你也应该明白了ai的训练原理了。同时你也应该会想到，如果我的数据完全胡编乱造呢？那么模型会学习到什么？

而且，假如我们的模型就是内置了一个$y=wx+b$的函数，我们投喂给它一些$y=ax^2$的数据，它怎么学？

**表示学习就是把输入的数据先学习出来一个函数，然后用这个函数来表示输入的数据，最后再用内置的回归函数模型来学习并调整参数**

用我们刚才的例子，表示学习就是先把我们的$y=ax^2$的数据，先学习出来一个函数$y=\sqrt{\frac{x}{a}}$,然后用这个函数就能把$ax^2$的转化为$x$，然后再用$x$套$y=wx+b$，然后就是上面机器学习的操作了

简单来说，就是数据可能不太适配模型，因此我们先通过一个函数调整输入数据，然后再用内置的回归函数模型来学习并调整参数

当然，调整参数的时候，两个函数模型都会进行调整

#### **深度学习**

显然，数据只进行一次$x^2->x$的转换是不一定可行的，有的时候我们需要更多的转换，来将更复杂的输入数据转为简单的数学表达式，再套用最内部的回归函数模型

因此，表示学习就是机器学习加了一个中间层，来转化数据

而深度学习就是表示学习的推广，它通过多个中间层，来表示更复杂的函数，从而实现更复杂的任务

那么，深度学习的流程也可以表示出来

```
内置多层函数模型，串行执行操作，即每个函数的结果作为下一个函数的变量进行计算
        ⬇️
根据输入输出动态调整每个函数
        ⬇️
足够的训练后，每个函数都达到一个理想的最优状态，从而对与输入数据进行最可能的输出
```

对于每个函数，它将原先的数据转化为全新的数据，我们称转化的结果为**特征**

而深度学习，就是将底层数据提取**特征**，再从这些特征提取**更高层的特征**，层层叠加，来调配各个函数与参数，得到最优的模型，从而预测输出

> 如果你有了解过，那么你可能会记得，每个函数实际的贡献值是不同的，因此会动态调配每个函数的贡献权重，这里是以参数调配来实现，也可以用加权等方式……毕竟我们的原理摆在这，具体的实现是多元的

```
另一种理解三大学习的方式：
机器学习本质就是内置一个函数模型$y=f(x)$,对于每个输入的$x$,我们动态调整$f(x)$的参数，来拟合数据

而表示学习是加了一个函数$y=g(x)$，则它的过程式：你输入$a$，先算出$y_1=g(a)$，然后算$y_2=f(y_1)$，然后$y_2$就是最终的结果

深度学习同理，$n$个函数$f_n(x)$，则当你输入x时，有：$y_1=f_1(x)，y_2=f_2(y_1)，y_3=f_3(y_2)......y_n=f_n(y_{n-1})$,最终结果就是$y_n$
```

### **附录**

**下面是我在学习机器学习时的实践代码（基于线性回归模型），没有通过NumPy，而是自己手写实现，来理解机器学习的原理。**

**因此，学习率我并没有动态变化，而是固定的。此外，这里为了防止单次数据对函数模型变化较大，我设置了一个最大步长，w,b的变化量不能超过这个最大步长**

**当然，实际实现肯定不是这样的，这里只是大致的一个流程，毕竟有想法实践一下，在我看来总是好的**

```python
import random
#线性模型 y'=wx+b
v=[]
#要求列表v中的元素为(x,y)的元组，输入w,b两个系数，返回一个float，为均方误差
def analyse_function(w,b)->float:
    if len(v)==0:
        print("样本不够")
        return 0
    sm=0
    for x,y in v:
        sm=sm+(y-(w*x+b))**2
    sm=sm/len(v)
    return sm
#两个动态变化的参数
w=0
b=0
#学习率，后续会根据数据动态调整，目前版本先为一个定值
Eta=0.052
#梯度裁剪上限，防止大x导致数值爆炸
CLIP=10.0
#梯度下降更新w,b
def update(x,y):
    global w,b
    r=w*x+b-y
    g_w=2*r*x
    g_b=2*r
    if g_w>CLIP:
        g_w=CLIP
    if g_w<-CLIP:
        g_w=-CLIP
    if g_b>CLIP:
        g_b=CLIP
    if g_b<-CLIP:
        g_b=-CLIP
    w=w-Eta*g_w
    b=b-Eta*g_b
if __name__=="__main__":
    while(1):
        opt=input("输入指令，1:录入数据，2:检查均方残差，3:预测，4.检查系数")   #只是用来分操作的
        if(opt=="1"):
            while(True):
                line=input().strip()      # 读取整行并去除首尾空白
                if(line=="exit"):
                    break   
                try:
                    x,y=line.split()       # 按空格拆分为 x 和 y
                    x=int(x)
                    y=int(y)
                except ValueError:         # 数字格式错误或个数不对都会触发
                    print("请输入两个整数，用空格分隔")
                    continue
                v.append((x,y))
                update(x,y)
        if(opt=="2"):
            print(analyse_function(w,b))
        if(opt=="3"):
            while(True):
                x=input()
                if(x=="exit"):
                    break
                try:
                    x=int(x)
                except ValueError:
                    print("请输入整数")
                    continue
                print(f"forecast:{w*x+b}")
        if(opt=="4"):
            print(f"w:{w}, b:{b}")
        if(opt=="exit"):
            break
```
