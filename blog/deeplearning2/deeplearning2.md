#### **一、工具：NumPy 和 Matplotlib**

先说 NumPy。上一周我还在手写 `for` 循环算均方误差，这一周终于用上 `np.array` 了，感觉像从算盘换成了计算器。

NumPy 最核心的东西就一个：`ndarray`。你可以把它理解成一个"能整体做运算的列表"。比如两个向量点乘，用 NumPy 就是一行：

```python
import numpy as np
w = np.array([0.5, 0.5])
x = np.array([1, 0])
res = (w * x).sum()
```

`w * x` 是逐元素乘，`.sum()` 是求和，合起来就是点积。你要是手写循环，得写好几行，还容易写错下标。NumPy 的好处就是**把"对每个元素做同样的事"这件事，变成一个整体操作**，这跟后面神经网络里"一层对一层做矩阵乘法"的思路是一脉相承的。

`np.arange(0, 6, 0.1)` 生成从 0 到 6、步长 0.1 的数组，`mb.plot` 画线，`label` 是图例名，`mb.legend()` 把图例显示出来，`mb.show()` 把图弹出来。就这样，没啥好说的。

#### **二、零件之一：激活函数**

激活函数这个词，上一周我完全没提。这一周看了才知道，它是神经网络里"非线性的来源"。先说结论：**没有激活函数，神经网络叠多少层都等价于一层线性变换**。这个结论我后面会解释，先看几个激活函数长啥样。

##### **阶跃函数**

最原始的激活函数，输入大于 0 输出 1，否则输出 0：

```python
def step_function(x: np.ndarray) -> np.ndarray:
    return np.array(x > 0, dtype=int)
```

`x > 0` 对数组里每个元素做比较，得到一个布尔数组，`dtype=int` 把它转成 0/1。这个函数其实就是感知机的"开关"：加权和超过阈值就"开"，否则"关"。

> 我一开始写的是标量版本，注释掉的那个：
> ```python
> # def step_function(x:float)->int:
> #     if(x>0):
> #         return 1
> #     return 0
> ```
> 后来发现传进来的是 `np.ndarray`，标量版本没法整体处理，就换成数组版了。这也是 NumPy 思维的一个体现：**能整体算就别循环**。

##### **sigmoid 函数**

$$\sigma(x)=\frac{1}{1+e^{-x}}$$

代码：

```python
e = 2.7182
def exp(x: float) -> float:
    return pow(e, x)

def sigmoid_h(x):
    return 1 / (exp(x) + 1)
```

> 这里我犯了个错，你眼尖的话应该看出来了：sigmoid 是 $\frac{1}{1+e^{-x}}$，我写成了 `1/(exp(x)+1)`，**少了个负号**。正确的应该是 `1/(exp(-x)+1)`。这个错误我写博客的时候才发现，代码就先留在这当反面教材了。另外 `e=2.7182` 是自己手打的近似值，正经写应该用 `np.exp`，精度和数值稳定性都好得多。

sigmoid 的好处是输出在 $(0,1)$ 之间，平滑可导，后面讲反向传播的时候会用到它的导数。阶跃函数在 0 点不可导，这也是它后来被 sigmoid/ReLU 取代的原因之一。

##### **ReLU 函数**

$$\text{ReLU}(x)=\max(0,x)$$

代码：

```python
def RELU_h(x):
    if x > 0:
        return x
    return 0
```

ReLU 就是"小于 0 归零，大于 0 原样输出"。简单、快、梯度好算，现在深度网络里用得最多。我这里写的是标量版，数组版一行就够：`np.maximum(0, x)`，留给你自己试。

> 三种激活函数放一起看：阶跃是"硬开关"，sigmoid 是"软开关"，ReLU 是"半边开关"。它们的共同作用是**给网络引入非线性**，具体选哪个，看任务和数值稳定性，这个我目前还没研究透。

#### **三、零件之二：感知机**

感知机这东西，说穿了就是"加权和 + 阈值"。上一周我讲的 $y=wx+b$，把 $b$ 换成阈值、把输出套个阶跃函数，就是感知机。

我这一周把 AND、OR、NAND、XOR 都写了一遍，代码如下：

```python
import numpy as np

class InputError(TypeError):
    pass

def AND(x: np.ndarray) -> bool:
    try:
        w = np.array([0.5, 0.5])
        res = (w * x).sum()
        if res >= 1:
            return True
        return False
    except ValueError:
        raise InputError

def OR(x: np.ndarray) -> bool:
    try:
        w = np.array([1, 1])
        res = (w * x).sum()
        if res >= 1:
            return True
        return False
    except ValueError:
        raise InputError

def NAND(x: np.ndarray) -> bool:
    try:
        w = np.array([-0.5, -0.5])
        res = (w * x).sum() + 1
        if res <= 0:
            return False
        return True
    except ValueError:
        raise InputError

def XOR(x: np.ndarray) -> bool:
    try:
        r1 = NAND(x)
        r2 = OR(x)
        return r1 and r2
    except InputError:
        raise InputError
```

> 这里 `InputError` 是我自己定义的异常，`try/except ValueError` 是为了捕获"x 和 w 大小不匹配"的情况。写的时候觉得挺规范，现在看有点过度设计了，不过留着也行，至少知道 `w * x` 维度不对会抛 `ValueError`。

重点说 XOR。AND、OR、NAND 都是**单层感知机能解决**的，但 XOR 不行。为什么？因为 XOR 的两个类在平面上是"对角分布"的，你画不出**一条直线**把它们分开。单层感知机只能画直线（线性决策边界），所以 XOR 它搞不定。

那怎么办？**叠一层**。XOR 可以拆成：`XOR(x) = NAND(x) AND OR(x)`。先用 NAND 和 OR 各算一个中间结果，再把这两个中间结果喂给 AND。这就是"多层"的雏形：**单层不够，就加中间层**。我代码里 `XOR` 调 `NAND` 和 `OR`，就是这个思路。

```
x1,x2 ──> NAND ──┐
      └──> OR   ──┴──> AND ──> 输出
```

这个图很重要，它其实就是后面神经网络"输入层→隐藏层→输出层"的最小例子。NAND 和 OR 是隐藏层，AND 是输出层。

#### **四、组装：神经网络的大体流程**

把上面的东西串起来，就是神经网络。我这一周理解的流程是这样的：

```
输入层 -> (转换矩阵 + 偏移向量) -> 下一层 -> (激活函数) -> (矩阵 + 向量) -> 下一层 -> …… -> 输出
```

用代码表示，我在 `ch3.py` 里搭了一个 `2 -> 3 -> 4 -> 1` 的网络，就是输入 2 维、中间两层分别 3 维和 4 维、输出 1 维：

```python
import numpy as np

# 2->3->4->1
x = np.array([1, 5])   # input
w1 = np.array([[1, 2, 3], [2, 3, 6]])
w2 = np.array([[3, 4, 2, 5], [6, 2, 3, 4], [5, 0, 2, 3]])
w3 = np.array([[0], [2], [3], [4]])
w1 = np.dot(w1, np.dot(w2, w3))
print(np.dot(x, w1))
```

> 说明一下：这段代码里我把 `w1、w2、w3` 直接连乘了，`np.dot(w1, np.dot(w2, w3))` 等价于先算 `w2·w3` 再算 `w1·(w2·w3)`，最后 `x·(...)`。**但这里其实没有加激活函数，也没有加偏移向量**，所以它本质上还是一个线性变换的连乘，等价于一个大矩阵。我写这段是为了验证维度能对上：`(2×3)·(3×4)·(4×1) = 2×1`，`x` 是 `2` 维，点乘完是标量。维度对上了，流程就通了。

这里有个关键点，也是我这一周最有收获的一个认识：

**如果每层之间只做矩阵乘法，不加激活函数，那么无论叠多少层，最终都等价于一层线性变换。** 因为 $(W_2 W_1)x = W x$，矩阵乘法的结合律把中间层"吃掉了"。所以激活函数不是可选项，是必需品——它负责在每层之间"掰弯"一下，让网络能拟合非线性函数。

加上激活函数和偏移向量之后，一层的前向计算就是：

$$y = \sigma(Wx + b)$$

`Wx` 是矩阵乘向量，`+b` 是偏移，`σ` 是激活函数。这一层的输出 `y` 作为下一层的输入 `x`，如此反复。这就是"前向传播"。

#### **五、还没搞定的：反向传播**

上面的流程，从输入到输出，叫**前向传播**。但网络怎么"学"？输出错了，怎么改 `W` 和 `b`？

上一周我讲的梯度下降，是"对损失函数求导，按导数方向更新参数"。放到神经网络里，问题变成了：**输出层的误差，怎么传到前面每一层的 `W` 和 `b` 上？** 这就是反向传播要解决的问题。

我目前的理解是：反向传播本质上是**链式法则**。输出层的误差对输出层参数求导好算，但隐藏层的参数离输出层远，得把误差一层一层"传回去"，每传一层乘一个局部导数。上一周我讲学习率的时候说"导数大于 0 就往减小方向走"，反向传播就是把这个"导数"从输出层一路算到输入层。

具体怎么算，我还没写出来。这一周先把前向传播跑通，反向传播留到下一周。目前我的状态是：**知道它要用链式法则，知道它是误差从后往前传，但具体推导和代码还没动手**。所以这篇博客标题写"摸到了门口"，不是谦虚，是真没进去。

### **附录**

**这一周的代码都在上面贴了，这里补充两点：**

**1. 关于 sigmoid 的那个负号错误**，正确的写法是：

```python
def sigmoid_h(x):
    return 1 / (np.exp(-x) + 1)
```

用 `np.exp` 而不是手打 `e=2.7182`，精度和数值稳定性都更好。这个错误提醒我：**公式抄代码的时候，负号、括号这种小地方最容易出错，写完最好拿几个点验算一下**。

**2. 关于 `2->3->4->1` 那段代码**，它只验证了维度，没有激活函数。如果加上激活函数，大概是这个样子（示意，没跑过）：

```python
def forward(x, w1, w2, w3):
    h1 = sigmoid_h(np.dot(x, w1))   # 2->3
    h2 = sigmoid_h(np.dot(h1, w2))  # 3->4
    y  = np.dot(h2, w3)             # 4->1，输出层不一定加激活
    return y
```

> 注意这里 `w1` 的维度得改成 `(2,3)`，跟上面 `w1` 的 `(2,3)` 一致，`np.dot(x, w1)` 才是 `(3,)`。上面那段连乘代码里 `w1` 被覆盖了，维度关系有点绕，这里以 `forward` 的写法为准。
